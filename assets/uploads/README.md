# Imagenes para la invitacion

Puedes subir aqui las fotos finales sin mezclarte con los assets originales de la plantilla.

Carpetas:

- `portada/`: imagen grande inicial. Sugerido: `portada.jpg` o `portada.png`.
- `pareja/`: fotos principales de Hector y Cynthia. Sugerido: `cynthia.jpg`, `hector.jpg`, `pareja.jpg`.
- `historia/`: fotos para la linea de tiempo. Sugerido: `historia-1.jpg`, `historia-2.jpg`, `historia-3.jpg`.
- `personas/`: papas, padrinos, damas, best men, abuelos o personas importantes. Sugerido: `persona-1.jpg`, `persona-2.jpg`, etc.
- `galeria/`: fotos para la galeria. Sugerido: `galeria-1.jpg`, `galeria-2.jpg`, etc.
- `evento/`: fotos de ceremonia, recepcion o lugar. Sugerido: `ceremonia.jpg`, `recepcion.jpg`, `codigo.jpg`.
- `itinerario/`: imagen decorativa para la tarjeta de itinerario. Sugerido: `itinerario.jpg`.

Recomendaciones:

- Formato JPG o PNG.
- Fotos optimizadas, idealmente menos de 1.5 MB cada una.
- Para portada, una imagen de al menos 1600 px en el lado largo.
