# Imagen de portada

La portada inicial de pantalla completa usa esta imagen:

```text
assets/images/cover/portada.png
```

Puedes reemplazar `portada.png` por una foto vertical u horizontal de buena calidad.
Si la foto final es JPG, tambien se puede cambiar la ruta en `index.html`.
Recomendado:

- JPG optimizado.
- 1600 px o mas en el lado largo.
- Menos de 1.5 MB si es posible.
- Que tenga espacio visual al centro, porque ahi van los nombres y el boton.
