# Audio de la invitacion

Coloca aqui la cancion de la invitacion con este nombre:

```text
cancion.mp3
```

Ruta esperada por la pagina:

```text
assets/audio/cancion.mp3
```

Recomendaciones:

- Usa MP3 para mejor compatibilidad.
- Idealmente que pese menos de 5 MB.
- No se reproduce automaticamente con sonido; la persona invitada decide si la activa o la pausa.
